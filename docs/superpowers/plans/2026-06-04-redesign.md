**Goal:** Redesign the Security Architecture Hub with a Clean Cyber aesthetic — Inter font, dark `#111d35` sidebar with readable `#7fa8cc` text, persistent `#060d1e` top header with hamburger-collapsible sidebar, and a new Cyber Security Architect placeholder section.
